# Limitations

This repository intentionally does not claim that a stable backtest pattern is a tradable edge.

Important limitations include:

- repeated testing / multiple-comparison risk
- selection bias
- non-independent trades
- changing market regimes
- spread
- commission
- slippage
- execution latency
- parameter overfitting
- data quality
- look-ahead mistakes
- survivorship of only the attractive patterns

The correct next step after research selection is a genuinely untouched out-of-sample test.

A public GitHub repository is also not a vault. Never commit the private core and assume deleting it later makes it disappear. Git history is annoyingly loyal.
